# Product Hunt

Lowest priority of the four. PH rewards polish and a gallery, and this is a
free toy with no signup — it will do fine but it is not where the audience is.
Ship HN and Reddit first.

**Name:** GrindBot

**Tagline** (60 char limit — this is 44):

```
A tiny robot yells at you while you work
```

**Description:**

```
GrindBot puts a small robot in the corner of your screen. Every so often it
appears, types one line, and disappears. Clicks pass straight through it, so it
never takes focus or interrupts what you're doing — it just judges you.

Every message is a plain text file. Five packs ship, from LinkedIn-parody
hustle to a genuinely bleak one called obituary, and you can point it at your
own file instead. Timing runs from 5 seconds to 5 hours.

macOS and Windows. Free, MIT, no account, no backend, no telemetry.
```

**First comment (maker):**

```
I built this for screen recordings — I wanted a running bit in the corner of
my footage that didn't involve touching my recording setup.

It turned into a small cross-platform exercise: two implementations, one config
format, and an overlay that has to draw over your work on both platforms
without ever stealing focus or swallowing a click.

The message packs are the actual product, and they're just text files. If you
write a better one, the repo takes pull requests.

Neither build is signed, so macOS needs a right-click → Open the first time and
Windows may show a SmartScreen prompt. Worth knowing before you download.
```
